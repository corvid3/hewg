bootstrapping hewg has been made easier.
simply, run ./bootstrap.sh. the script will pull all required
libraries and install them to a bootstrapping directory,
and then run the bootstrapping makefile. 

the bootstrap hewg executable can be found in ./bin/hewg.

then, create ~/.hewg/targets/x86-linux-gnu (or whatever other triplet you're on)
and update the config with in your toolchain. an example can be found
at the end of this file.

make sure to rebuild the hewg project with the bootstrapped executable
to get all available features.

ex. toolchain:

[tools]
cxx = "x86_64-pc-linux-gnu-c++"
cc  = "x86_64-pc-linux-gnu-cc"
ld  = "mold"
ar  = "ar"

[directories]
include_dirs = { "/usr/include" "/usr/local/include" }
lib_dirs = { "/usr/lib" "/usr/local/lib" }
